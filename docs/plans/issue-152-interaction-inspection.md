## Target and display contract

All visible is dynamic over current visible entries; ordinary component visibility
and isolation remain display gates. Ligand mode requires explicit existing assigned
ligand-instance choice, keyed by entry/component identity and complete resolved
canonical membership. Do not invent multi-residue molecule grouping from per-residue
navigation components. Unqualified/ambiguous instances use explicit selection mode.
Known connections crossing multiple nonpolymer instances must be explained rather
than silently treating one residue as a whole multi-residue ligand.

Use selection captures exact `(entry_id, atom_id)` references. Later selection
changes, including Select participants, never retarget it. Update is explicit.
For participant groups G0/G1 and captured set S, accept a target-to-rest record
exactly when `(G0 intersects S) XOR (G1 intersects S)`. Keep both entire groups,
endpoints, geometry and canonical Inter/Intra classification unchanged. This
includes full ring/donor-H/charge sites touched by a selected member without
altering the global molecular selection or qualifying partial chemistry.

Selection captures retain their exact identities while all remain valid, even if
other atoms are added. Ligand captures require the same instance and identical
full membership; added/removed members require explicit Update. Coordinate/order/
charge changes with valid membership retain target intent but retire old results
and details. Missing current complete projections mean validating, not deleted.
Hidden targets retain intent with feedback. Deleted/changed targets show a clear
unavailable/update state, never fallback to All visible or a different ligand.

Analyze immutable visible artifact identities using the existing cache/profile.
Targets, categories, styles and master visibility cannot modify classification.
Native receipts identify the exact requested display and scene generation, publish
pending before invalidation, and report ready counts/keys only after successful
current installation using native hydrogen visibility. App guards project/viewer/
display identity; lazy unmounted adapters cannot claim successful rendering.
